# 从视觉气质到真实任务

下列都是独立适配例子，不是 Anthropic 产品截图的测量或复刻。所有尺寸、颜色、数量化布局建议均是适配建议；按实际设备和内容验证。

## 内容出版：先让文章被读懂

**场景**：从零制作一份面向公众的独立科学刊物网站，包含首页、文章和专题页；品牌有蓝色，长文有公式或图表。

- 用编辑式节奏、行宽与标题层次表达平静感，保留蓝色品牌和必要图表语义；不套用产品销售首页。
- 文章以真实段落、图注和引用组织。目录是否需要取决于篇幅，不默认把所有页面做成居中短卡片。
- 新建共享导航、文章排版和专题列表组件；不凭风格添加登录、定价或订阅支付。
- 检查中文长文、图注、窄屏图表、链接焦点与跨页返回路径。缺文章内容时使用明确标记的样稿，不伪造引用。

## 消费产品：安静不能牺牲决策信息

**场景**：鲜明绿色品牌的户外用品商店，需要产品列表和商品详情，含规格、库存、价格和筛选。

- 保留品牌与商品图片的表现力，用间距、对齐和信息顺序降低噪声，不把全部页面改成米白。
- 列表服务比较，详情服务判断；规格、库存、配送条件等已有信息不能为留白隐藏。
- 保留已定义的筛选与选择逻辑，关键状态同时有文字。没有真实支付接入时明确说明，不把前端演示称为可下单商店。
- 验收长商品名、多规格、无库存、筛选结果为空与窄屏布局。

## 创作工具：让作品活跃，让控制区清楚

**场景**：深紫品牌的多页音频创作应用，包含作品库、编辑器和导出页。

- 平静感主要用于工具栏和属性区，作品、波形与播放反馈保留必要颜色及动态；不强制黑白或宣传页布局。
- 共享导航、作品身份与保存状态保持一致，编辑器可采用比作品库更高的密度。
- 空间优先分给编辑对象，不能用巨大标题挤压时间轴。按已有技术栈实现；新建时仅实现请求范围。
- 验证键盘路径、播放状态、长作品名、未保存退出与跨页返回；这些行为若未授权或尚无实现，只列缺口，不伪造完成。

## 管理列表：减噪，不减信息

**场景**：运营人员在已有多页后台中管理记录，常用筛选、找异常、查看详情。

**之前**：巨大欢迎语、无用统计卡、多层卡片包着表格；每行所有按钮都是黑色；状态用很浅的绿字；表格行高导致常用记录需要反复滚动。

**之后**：
- 保留侧栏、路由、筛选逻辑和现有表格能力。缩短页头，让任务名和新增动作同排。
- 过滤、搜索和结果数量放在同一工具区域；不频繁使用的动作收进有明确名称的菜单。
- 去掉无任务价值的欢迎区与重复卡片外框，表格保留清晰表头和行分割。
- 行操作采用克制的文本按钮；真正的主要动作集中在页面任务区域。
- 状态用可读文字配小型标记；异常有清楚标签。颜色不再承担全部含义。
- 数字列对齐，空值有一致表达。批量选择时显示相关操作，不让平时的工具栏挤满按钮。
- 窄屏保留关键字段，并明确提供详情/横向滚动；删列需要产品依据，不凭美观决定。

**可借鉴的气质**：不抢数据的表面、减少视觉竞争。**必须偏离的地方**：紧凑密度和操作可见性优先。验收看异常记录是否更容易定位；没有用户测试时不声称效率提升。

## 编辑式首页：表达清楚，不用气氛代替内容

**场景**：一个软件产品的介绍首页，目标是让访客理解价值并开始试用。

**之前**：套用含糊的「重新定义未来」巨型衬线标题；多块相同米色卡片；所有按钮同样显眼；首屏缺少产品实际样子。

**之后**：
- 用具体标题说清产品解决什么任务；副标题只解释目标用户和结果。
- 英文展示标题可用系统衬线；中文标题先检验实际字形，不强求同样的视觉宽度。
- 设置清晰主 CTA 与次要了解入口；若核心目标是登录，则聚焦登录区域，而非强制增加营销章节。
- 展示真实产品画面或工作结果；没有素材时用诚实的简洁演示，不伪造客户评价与数据。
- 章节由内容重要性决定，背景与留白建立阅读节奏，不把每段都塞进圆角卡片。
- 移动端标题自然换行，CTA 易触达；不要为了保住桌面构图压小正文。

**可借鉴的气质**：编辑式标题与工具型控件的对比、聚焦、从容节奏。**必须保留自己的东西**：品牌名字、价值主张、素材与措辞，不模仿 Anthropic 的身份标识。

## 颜色和密度的落地判断

| 需求 | 倾向 | 验证 |
| --- | --- | --- |
| 长文阅读 | 限制正文行宽，放松段落节奏 | 中文换行、放大后可读性 |
| 高频列表 | 稳定列宽、紧凑行、清晰表头 | 扫读与键盘操作 |
| 触屏确认 | 宽裕点击目标、动作分离 | 站姿可读、误触和返回路径 |
| 提示/辅助文字 | 低于正文但仍清晰的对比 | 在实际背景上算对比 |
| 浮层 | 用遮挡、边界与必要阴影表示层级 | 焦点进入与返回、关闭方式 |
| 品牌强调色 | 少量赋予行动/选中角色 | 不与警告、错误混淆 |

## 交付时的简短说明模板

「保留了 [现有结构]；针对 [关键任务] 调整了 [层级/排版/边界/状态]。这次采用的是 [界面模式]，不是把官网样式复制到全部页面。已验证 [证据]；[未验证项] 仍需确认。」

说明实际完成的工作即可；不要求为了套模板增加实现范围。
