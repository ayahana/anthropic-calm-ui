## 样本与观察

### 1. Claude 官网

来源：https://claude.com/

- 暖白底、近黑文字。大号衬线主标题居中；副标题也是衬线；导航、按钮与辅助说明是无衬线。
- 首屏主任务只有一个中心组：标题 → 简短副标题 → 登录方式 → 下载入口。登录面板窄于标题，大圆角、细浅边框、极淡阴影；没有大量装饰性容器。
- 深色实心按钮明确主操作；Google 入口及下载按钮以浅底细边呈现。说明文字小而降调，但不是完全隐藏。
- 左上品牌标识带少量陶土橙色，其余首屏基本中性。大量空白不是没有组织：中心轴、统一按钮宽度与清晰垂直分组保持结构。
- 滚动后顶部导航仍可见。套餐区在当前宽度是双列白色圆角卡片，卡片间距明显；卡内依次是线描插图、衬线套餐名、用途、价格、主按钮和功能列表。内容由细横线分隔。

### 2. 定价页：信息密集但保留清楚层级

来源：https://claude.com/pricing

- 首屏沿用居中衬线标题；增加细分隔的第二级导航行，明确页面所在位置。
- Individual / Team & Enterprise / API 为同一浅暖灰胶囊组中的分段选项。实测点击 Team & Enterprise 后，白色选中块移动到对应项，内容替换为团队与企业两列卡片。
- 选中态靠底色差异、文字与位置体现，并非饱和色。卡片仍是白底、细浅边、大圆角。企业卡同时有深色主按钮和浅色次按钮。
- **可迁移原则**：分类先行、同层级项目使用相同骨架；依靠对齐、分组、字重和留白减轻信息量，而不是把每条信息都加颜色。
- 未检查 API 面板、全部比较表或键盘行为。此处不记录价格，因为价格不是设计规则且可能因地区变化。

### 3. Claude Code：营销页面与应用界面必须区分

来源：https://claude.com/product/claude-code

- 页面采用双层导航、非常大的衬线产品名、两行无衬线解释、并排主/次操作，下方是平台入口小卡片序列。
- 平台小卡片以图标和简短文字组成；外框与底色很轻，不与主 CTA 争夺注意力。
- 下方官方应用预览置于宽幅白色圆角框内，并用淡阴影与底图区分。
- **预览中可见而非真实应用验证**：窄左侧栏承载导航/历史；主区更宽；当前条目为浅底强调；聊天消息、工具执行说明、代码差异各有不同层次。代码使用等宽字，增删内容使用有语义的绿/红；输入框在下方，附加工具以小图标与短标签呈现。
- 可提炼的是“外围导航安静、工作内容居中、颜色用于状态与内容语义”。不能据宣传预览认定所有产品的布局或行为都相同。

### 4. Artifacts 功能页

来源：https://claude.com/features/artifacts

- 小型类别标签 → 大型两行衬线标题 → 无衬线说明 → 一个深色主按钮 → 较小适用范围说明。标题大小明显高于正文，层级不依赖多种颜色。
- 下方宽幅白色媒体容器为大圆角、细边。视频封面展示少量产品状态文字与橙色小标记，播放按钮是浅色圆角方块；未播放或操作真实 Artifact。
- **可迁移原则**：用真实工作样例替代泛化装饰，演示区域和主要行动分开；辅助信息降调但可找。

### 5. Anthropic 公司首页：与 Claude 产品品牌同源但不相同

来源：https://www.anthropic.com/

2026-11-03 补充：当前深色浏览器偏好下，主体浅色、底部 footer 深色；不是全页单一浅色主题。分区实际色值、时间与限制见 [主题复核记录](theme-behavior.md)。以下其余结构描述仍为 v1 历史观察。

- 浅暖色画布，导航是轻边框胶囊，品牌字标为粗无衬线。与 Claude 官网的文本导航不同。
- 顶部使命陈述为宽幅文字：开头粗无衬线，后续衬线；不是所有标题一律衬线。
- 主报告区域使用编辑式拼贴小图、有限色彩和居中标题。页面提供 Pause animation 控件；未测试其效果或运动时长。
- 新闻模块为浅暖灰大卡片，信息次序为类别/日期、粗无衬线标题、简介、细线分隔的资料链接和横向操作入口。更多内容通过规则化结构而不是更重阴影表达。
- 页面加载初期截图曾呈空白/淡入中间态；后续截图确认完整内容。不能把加载中的空白当成最终留白设计。

### 6. Claude’s Constitution：长阅读模板

来源：https://www.anthropic.com/constitution

- 暖灰底、居中线描插图，插图含橙色点缀。大标题为粗无衬线，副标题与正文使用衬线。
- 正文为比页面窄得多的居中阅读栏；视觉估计约 700 像素宽，但未作 CSS 测量。主标题与正文之间有明显留白，正文段落间隔可辨。
- 首屏正文不采用卡片包裹，避免“每段一个框”的碎片化；文字本身成为主要视觉材料。
- 左下可见小型 Listen to the audiobook 控件；未播放。
- **反例约束**：不要把“Anthropic 风格”简化成“衬线标题＋无衬线正文”。正确规则是按角色决定字体，长文与产品营销有不同的阅读目标。

## 公开品牌资料：事实与适用边界

来源：https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md?plain=1

该官方示例 skill 给出：深色 `#141413`、浅色 `#faf9f5`、中灰 `#b0aea5`、浅灰 `#e8e6dc`；强调色橙 `#d97757`、蓝 `#6a9bcc`、绿 `#788c5d`。字体建议为标题 Poppins、正文 Lora，并带 Arial/Georgia 回退。

这些是**该文件的指引**，不是本次网页测量值。文件有 PPT/python-pptx 语境，不能把它当作 Claude 全产品 CSS、字体授权或完整 UI 规范。用于原创项目时，建议转化为“暖中性色＋少量强调色＋明确字体角色”的语义 token，而非承诺精确品牌复刻。

## 建议写进 skill 的原创规则（研究推论，非官方规范）

1. 先选模板：营销、长阅读、信息比较、工作区；不把所有页面都套同一个 hero。
2. 用字号、字重、对齐、阅读宽度和段落节奏建立层级，再决定是否需要边框/底色。
3. 暖中性画布与强文字对比并存；“柔和”不等于低可读性。对比度需另行测试。
4. 主操作深色实心，次操作轻边框/浅底，同一局部避免多个同等强烈 CTA。
5. 较大的组间距、较小的组内距；只在真正成组内容上使用卡片。
6. 颜色优先承担品牌点缀与状态语义；不让按钮、装饰、标题同时争抢注意力。
7. 人文感来自有限的衬线文字、线描/编辑式插画和自然语气；不是靠满屏米色或重复 logo。
8. 工作区需要紧凑导航与内容优先；营销页面可宽松，不能把同一密度强加给高频任务。
9. 所有未观测交互（hover/focus/error/loading/dark/mobile）按通用可访问性与产品需求另行设计和测试，不冒称来自 Anthropic 实测。
10. 交付验收同时看截图和操作：阅读顺序、可识别主操作、长文本、窄屏、焦点与状态反馈；“舒服”必须可解释、可检查。
