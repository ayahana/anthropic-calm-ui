## 边界与尚未验证的内容

- 所有颜色都是设计建议；深色方案是深炭色适配，未据实机观察推断 Claude 深色 UI。
- 文字采用普通文字 4.5:1 门槛；控件边界与焦点采用 3:1 门槛。焦点计算只覆盖以上相邻背景，未覆盖任意图片、彩色容器或裁切情形。
- `border-soft` 只用于装饰性分隔，未作为必需控件识别边界验收；不要用它替换 `border-control`。
- 仅检查列出的实色配对。透明度、叠加层、禁用态、其他背景、渐变、抗锯齿、实际字号、hover/pressed/selected/error 的完整组件呈现未由此证明。
- 此计算不等于完整 WCAG 合规：还需验证语义、键盘、焦点顺序和可见性、屏幕阅读器名称、缩放重排、触控目标及真实界面所有适用状态。
- 若更改 token 或应用到其他背景，应重新计算并用真实内容与设备检查；不要把本表当成对任意使用方式的保证。

## 复现与标准来源

在技能目录 `anthropic-calm-ui/` 内运行 `python3 scripts/check_contrast.py`；机器可读输出加 `--json`。脚本位于 [scripts/check_contrast.py](../scripts/check_contrast.py)，随完整技能文件夹安装，不依赖仓库外文件。仓库根目录也提供同名入口，调用这一份实现。结果直接来自 CSS，不以这份静态表为测试输入。修改颜色后以脚本结果为准，并更新本表。该脚本只识别当前文件两个选择器中的六位十六进制实色。

- [WCAG 2.2 非文本对比说明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)：3:1 针对识别控件/状态所需视觉信息与相邻颜色，不要求所有装饰边线都满足；不对比同一元素先后两个不相邻状态的颜色。
- [WCAG 2.2 指针目标最小尺寸说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：24 × 24 CSS px 或满足相应例外；尺寸/间距门槛不等于触屏终端已经好用。
