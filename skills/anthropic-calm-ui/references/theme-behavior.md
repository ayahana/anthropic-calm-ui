## 证据强度与限制

- 当前 `matchMedia("(prefers-color-scheme: dark)")` 为 true、light 为 false，是页面所接收偏好的直接证据。
- 两次可见外观变化与用户提示、当前深色媒体查询相符，支持该 Claude 首页响应深色偏好的解释。但第一轮没有媒体查询记录，不是严格控制其他变量的完整双状态实验。
- 浏览器设置页面无法在当前获准访问范围内读取，未直接核实用户具体改变了哪个设置；没有为检查而绕过限制。
- 未穷尽站内手动选择、存储状态、所有子页面、地区、账号或设备的变化。
- 未重新尝试登录；Claude 应用、原生 App 与 Console 的实际操作仍未验证。
- 本项目深色 token 是独立适配方案，不是从两项 body 颜色推导出的官方完整深色设计系统。
